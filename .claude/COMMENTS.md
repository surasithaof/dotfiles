# Comments

No comments by default. Add one only when the code can't carry its own why (hidden constraint,
subtle invariant, workaround, non-obvious magic number) — never to restate what the code already
says. Max one line, two if truly needed. No comment headers, no docstring paragraphs, no restating
the function/variable name in prose. If explaining it needs more than that, simplify the code
instead of writing more comment.
