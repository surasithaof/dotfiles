# Git / PR attribution

- No Co-Authored-By or "🤖 Generated with Claude Code" line in commits (global setting
  `includeCoAuthoredBy: false`) — don't add either even if a past commit here has one.
- Do not include the chat/session URL (e.g. a "Claude-Session: ..." line or a
  claude.ai/code/session link) in commit messages or PR descriptions.
